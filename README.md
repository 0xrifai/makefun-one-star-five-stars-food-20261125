## The idea

An alien tourist hands planet Earth a one-star review — customs confiscated a spare tentacle, and it rained on the parade — yet still slips in a real compliment about the food: the empanadas were so good the visitor has applied for Earth citizenship.

The entry is a single sentence, written by `main.ts` to `/output/entry.txt`.

## Run

```sh
npm install
npm start
```

The program writes one sentence (at most 200 characters) to `/output/entry.txt`.

## The sentence

> One star: customs confiscated my spare tentacle and it rained on my parade, but the empanadas were so good I have applied for Earth citizenship.

One sentence, 144 characters: a one-star alien review of Earth that still lands a genuine compliment about the food.
